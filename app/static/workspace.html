Отдельный генератор ↗

Можно генерировать без создания задачи. При сохранении без пары Jira ID и название задача получит имя «Без названия N». Одна кнопка сохраняет настройки, аккаунты и текущие кейсы.

Генератор · параметры и кейсы

У задачи один набор кейсов. Генерация заменяет его содержимое после сохранения. Регион сохранённой задачи закреплён; для другого региона создайте новый черновик.

Пользователи выбранного региона

ID аккаунта, логин и пароль для заполнения кейсов. Выберите аккаунт в списке напротив кейса. Данные из генератора добавляются при сохранении. Этот список общий для ваших задач выбранного региона.
