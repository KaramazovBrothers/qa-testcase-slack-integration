Проверки депозитов у агрегатора

Инструкция

  1. Выберите тип интеграции, лицензию и регион. Валюта и браузеры подставятся автоматически.
  2. Укажите возможности метода: изменение суммы, обязательный чек, OneClick, QR, таймер и кнопка отмены. Для QR выберите способ сканирования и поведение на мобильных устройствах.
  3. Заполните данные аккаунта, метода и суммы. Для COM заполните блок USD-пользователя.
  4. Нажмите Сгенерировать кейсы и проверьте результат. Если оставлены параметры-заглушки, замените их перед отправкой.
  5. Если в наборе есть WebView, приложите APK-файл.

Настройки

Google Pay: основной метод — браузеры и WebView, второй — нативное приложение.

При выборе обеих карт: один кейс с Visa, остальные с Mastercard.

Основной пользователь и метод

COM: отдельный USD-пользователь

Для COM обязательна проверка с отдельным пользователем, у которого валюта аккаунта USD. Проверка по возможности совмещается с другим кейсом.
