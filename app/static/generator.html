Проверки депозитов у агрегатора

Подготовка и запуск тестов

1. Подготовить пользователя
  1. Создать нового пользователя под конкретного агрегатора.
  2. Через запрос финансистам в Slack-канале financial-transactions-qa верифицировать пользователя и попросить включить отметку Is test в продуктовой админке.
  3. В админке Cashdesk в разделе Unrestricted display выбрать Restricted.
  4. В Available Payment Methods оставить только один метод оплаты — тот, который тестируем, — и нажать save.
  5. Авторизоваться этим пользователем на сайте и проверить, что в депозитной вкладке доступен только тестируемый метод.

Нажмите на изображение, чтобы увеличить.

Пример Is test в продуктовой админке

Для COM подготовьте также отдельного USD-пользователя по этим же шагам.

2. Сформировать запрос агрегатору
  1. Выберите тип интеграции, набор, лицензию и регион. Валюта и браузеры подставятся автоматически.
  2. Минимальный набор — минимально необходимый объём обязательных тестов для случая, когда провайдер готов провести ограниченное количество проверок. Максимальный набор — полный набор применимых сценариев и региональное покрытие браузеров для случая, когда провайдер готов выполнить все проверки самостоятельно.
  3. Укажите возможности метода: изменение суммы, обязательный чек, OneClick, QR, таймер и кнопка отмены. Для QR выберите способ сканирования и поведение на мобильных устройствах.
  4. Заполните данные аккаунта, метода и суммы. Для COM заполните блок USD-пользователя.
  5. Нажмите Сгенерировать кейсы и проверьте результат. Если оставлены параметры-заглушки, замените их перед отправкой.
  6. Нажмите Копировать всё и отправьте запрос агрегатору. Если в наборе есть WebView, приложите APK-файл.

Настройки

При выборе минимального набора недостающие кейсы заказать у региональных QA без оплаты. Обязательно проверить открытие платёжных приложений через QR или кнопку на мобильных устройствах, включая WebView и нативное приложение, если метод поддерживает такие переходы.

Основной пользователь и метод

COM: отдельный USD-пользователь

Для COM обязательна проверка с отдельным пользователем, у которого валюта аккаунта USD. Проверка по возможности совмещается с другим кейсом.
